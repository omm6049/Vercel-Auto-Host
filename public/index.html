🌐 Telegram Webhook Sync (For Vercel 24/7 Hosting) Auto Sync

If hosted on Vercel, click below to link your live Vercel URL directly with Telegram's Webhook API so your bot responds 24/7 in the cloud.

1. Telegram Bot Token TELEGRAM_BOT_TOKEN

Create a bot via @BotFather on Telegram, type /newbot, and copy the API token into your .env file.

2. Vercel Access Token VERCEL_TOKEN

Generate a Personal Access Token from your Vercel Account Settings → Tokens page with Full Account or Deployment access.

3. Vercel Blob Read-Write Token (Optional) BLOB_READ_WRITE_TOKEN

Create a Blob Storage in your Vercel Dashboard under Storage → Blob to enable cloud backups of uploaded files.
